## 🚀 Projetos em destaque

### 1. SmartDesk AI — Central de Triagem Inteligente

![Status](https://img.shields.io/badge/status-conclu%C3%ADdo-brightgreen)

Projeto de automação inteligente para triagem de chamados. O fluxo utiliza IA generativa para classificar solicitações, identificar prioridades, gerar resumos e sugerir a equipe responsável. Os registros são armazenados no Supabase e apresentados em um dashboard com indicadores para apoiar a análise dos chamados.

**Tecnologias:** n8n · Gemini · Supabase · IA generativa · Dashboard

- [Repositório no GitHub](https://github.com/marialuiza-mdealcantara/smartdesk-ia)
- [Vídeo de demonstração](https://youtu.be/8HmBd0GEog4)

> A interface do dashboard foi criada com apoio de uma ferramenta de geração de código por IA, a partir dos requisitos definidos para o projeto.

### 2. Inventory System — Sistema de Gestão de Estoque

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-blue)

Sistema de gestão de estoque que está sendo desenvolvido em etapas. A proposta é centralizar o cadastro e o acompanhamento de produtos, níveis de estoque, anúncios em plataformas de venda, vendas e relatórios gerenciais.

A arquitetura planejada contempla um aplicativo para iOS em **SwiftUI**, um backend em **Python com FastAPI** e persistência de dados em arquivos JSON no Google Drive.

**Tecnologias:** Swift · SwiftUI · Python · FastAPI · JSON · Google Drive

- [Repositório no GitHub](https://github.com/marialuiza-mdealcantara/inventory-system)
